Cómo clasificar

Guía rápida para que todas usen el mismo criterio.

  1. Revisa insignia, botones, cierres y bastas.
  2. Mira la prenda a contraluz: busca manchas y desgaste.
  3. Asigna el estado según la pauta, sin excepciones.
  4. Toma la foto sobre fondo claro, prenda estirada.
  5. Escribe el defecto aunque sea chico.
  6. Pon el código impreso en la etiqueta física de la prenda.

Lista de retiro. Antes de entregar, revisa el número de pedido y quién está autorizado a retirar.

Al aprobar un reembolso, las prendas vuelven automáticamente al catálogo.

Guardar los cambios de verdad

Importante: lo que agregas en este panel se guarda en el navegador de este computador. Para que lo vea todo el mundo, descarga el archivo y súbelo a GitHub.

  1. Aprieta "Descargar PRENDAS actualizado".
  2. Abre js/datos.js en Visual Studio Code.
  3. Reemplaza el bloque const PRENDAS = [ … ]; por el del archivo descargado.
  4. Guarda y sube el cambio a GitHub.
